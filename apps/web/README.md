# Inwell — Корпоративный Fit-Checkup

Лендинг для B2B-услуги Inwell: выездной биометрический аудит физического состояния сотрудников.

**Домен:** [www.inwell.uz](https://www.inwell.uz)

Сайт полностью статический — без сервера и без базы данных. Связь с клиентом идёт
напрямую через телефон, Telegram и Instagram (раздел «Контакты»), формы на сайте нет.

## Локальная разработка

```bash
npm install
npm run dev
```

## Сборка для хостинга (cPanel)

```bash
npm run build
```

Содержимое папки `dist/` загрузите в `public_html` на cPanel:

- `index.html`
- папка `assets/`
- `logo-single.png`, `IMG_0414.png`
- `certificate-corporate.jpg`, `certificate-personal.jpg`
- `Inwell-Presentation.pdf`, `Inwell-Corporate-Report.pdf`, `Inwell-Personal-Report.pdf`
  (замените на свои реальные файлы с такими же именами)

Никакого PHP, почтовых настроек или базы данных не требуется — просто статические файлы.
